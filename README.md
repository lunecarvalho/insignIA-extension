# InsignIA — Chrome Extension 

## Sobre o projeto

O **InsignIA** é uma extensão para navegador desenvolvida com foco em **suporte inteligente**, organização de atendimentos e aplicação de **Inteligência Artificial (IA)** e **Processamento de Linguagem Natural (NLP)**.

O projeto tem como objetivo auxiliar equipes de suporte na análise e gestão dos atendimentos, permitindo a classificação de contatos, identificação de demandas e geração de insights para otimizar processos.

A extensão está sendo desenvolvida utilizando **TypeScript** e a arquitetura **Chrome Extensions Manifest V3**.
